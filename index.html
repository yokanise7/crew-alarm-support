出場アラームとは

1

What is CrewAlarm?

CSVから一括作成

勤務表CSVを読み込むだけで、その勤務に必要な起床・出場・確認通知のアラーム候補を自動で作成します。

泊まり＋明けに対応

日勤だけでなく、泊まり勤務と明け勤務の組み合わせにも対応します。勤務セット編集で事業者ごとの勤務名や組み合わせに合わせられます。

端末内で処理

CSVデータやアラーム情報は端末内で処理されます。ログインや外部サーバー通信はありません。

Create alarms from CSV

Import a duty roster CSV file, and the app automatically prepares wake-up, report, and check notification alarms for that duty.

Supports stay and after-duty patterns

The app supports day duties as well as stay-and-after-duty combinations. Duty Set Edit helps match your operator’s duty names and pairings.

Processed on your device

CSV data and alarm information are processed on your device. No login or external server communication is required.

Initial setup

まずはこの順番で進めてください

  1. アプリを起動し、通知やアラームの許可を確認します。
  2. NumbersまたはExcelでCSVファイルを作ります。
  3. CSVファイルをiPhoneの「ファイル」アプリに保存します。
  4. アプリの「CSVを読み込む」から勤務表CSVを選択します。
  5. 必要に応じて勤務セット編集で、泊まりと明けの組み合わせを設定します。
  6. 勤務セットと勤務名を選び、「この勤務で全アラーム登録」をタップします。

許可について

アラーム、事前通知、Live Activity表示、ウィジェット更新のために、iOSの許可や設定確認が必要になる場合があります。表示されたら許可してください。

通知AlarmKitLive ActivityWidget

Follow these steps first

  1. Open the app and allow notifications or alarms if prompted.
  2. Create a CSV file using Numbers or Excel.
  3. Save the CSV file to the Files app on iPhone.
  4. Select your duty roster CSV from “Import CSV”.
  5. If needed, configure stay/after-duty pairings in Duty Set Edit.
  6. Select the duty set and duty name, then tap “Register all alarms for this duty”.

Permissions

iOS may ask for permission to use alarms, notifications, Live Activities, and widget updates. Please allow them when prompted.

How to prepare a CSV file

必要な列名

CSVには、以下の列名を含めてください。複数の出場時刻は、1つのセルの中でカンマ区切りにします。英語の列名にも対応しています。

勤務名,カテゴリ,基準アラーム時刻（カンマ区切り）,基準起床時間,確認通知の時間
A1,平日日勤,"07:11,10:23,13:28",06:40,07:38
B1,平日泊まり,"16:54,19:34,22:45",15:30,
C1,平日明け,"07:13,10:18",06:40,07:37
勤務名カテゴリ基準アラーム時刻
カンマ区切り		基準起床時間確認通知の時間
A1平日日勤07:11,10:23,13:2806:4007:38
B1平日泊まり16:54,19:34,22:4515:30
C1平日明け07:13,10:1806:4007:37

勤務名はA/B/Cに固定されていなくても、カテゴリが正しく設定されていれば利用できます。

Required column names

The CSV file must include the following columns. If there are multiple report times, put them in one cell separated by commas. English column names are also supported.

Duty Name,Category,Base Alarm Times,Wake-up Time,Check Notification Time
A1,Weekday Day,"07:11,10:23,13:28",06:40,07:38
B1,Weekday Stay,"16:54,19:34,22:45",15:30,
C1,Weekday After,"07:13,10:18",06:40,07:37
Duty NameCategoryBase Alarm Times
comma-separated		Wake-up TimeCheck Notification Time
A1Weekday Day07:11,10:23,13:2806:4007:38
B1Weekday Stay16:54,19:34,22:4515:30
C1Weekday After07:13,10:1806:4007:37

Duty names do not need to be fixed to A/B/C as long as categories are set correctly.

時刻は「07:30」のように24時間表記で入力してください。Excelの場合は「CSV UTF-8」で保存すると文字化けを防ぎやすくなります。
Enter times in 24-hour format, such as “07:30”. If you use Excel, saving as CSV UTF-8 helps avoid garbled text.

CSVをiPhoneに保存して読み込む方法

5

Saving the CSV file to iPhone and importing it

iCloud Driveを使う

  1. MacやWindowsでCSVを作成します。
  2. iCloud DriveにCSVファイルを保存します。
  3. iPhoneの「ファイル」アプリを開きます。
  4. 出場アラームで「CSVを読み込む」をタップし、そのCSVを選びます。

AirDropを使う

  1. MacでCSVファイルを右クリックします。
  2. 「共有」→「AirDrop」を選びます。
  3. 自分のiPhoneを選びます。
  4. iPhone側で受け取り、「ファイル」アプリに保存します。

メールやLINEから保存

  1. CSVファイルをメールやLINEでiPhoneに送ります。
  2. 添付ファイルを開きます。
  3. 共有ボタンから「ファイルに保存」を選びます。
  4. 保存後、出場アラームからCSVを読み込みます。

Use iCloud Drive

  1. Create the CSV file on Mac or Windows.
  2. Save the CSV file to iCloud Drive.
  3. Open the Files app on iPhone.
  4. In CrewAlarm, tap “Import CSV” and select the file.

Use AirDrop

  1. Right-click the CSV file on Mac.
  2. Choose Share → AirDrop.
  3. Select your iPhone.
  4. On iPhone, accept the file and save it to the Files app.

Save from email or messaging apps

  1. Send the CSV file to your iPhone by email or messaging app.
  2. Open the attached file.
  3. Use the share button and choose “Save to Files”.
  4. Import the saved CSV from CrewAlarm.

アラームを登録する

Registering alarms

登録手順

  1. 勤務セットを選択します。
  2. 勤務名を選択します。
  3. 泊まり勤務では、勤務セット編集で保存した「泊まりと明けの組み合わせ」を優先して明け勤務を選びます。
  4. プレビューを確認し、「この勤務で全アラーム登録」をタップします。

基準時刻とアラーム時刻

基準時刻は勤務表上の元時刻です。アラーム時刻は、設定した「○分前」を引いた実際に鳴る時刻です。

例：
基準時刻 07:30
出場アラーム 5分前
実際に鳴る時刻 07:25

Steps

  1. Select a duty set.
  2. Select a duty name.
  3. For stay duties, the app prioritizes stay/after-duty pairings saved in Duty Set Edit.
  4. Confirm the preview, then tap “Register all alarms for this duty”.

Base time and alarm time

The base time is the original time from the duty roster. The alarm time is the actual time after subtracting the configured offset.

Example:
Base time 07:30
Report alarm 5 minutes before
Actual alarm time 07:25

勤務セット編集

7

Duty Set Edit

勤務セットとは

日勤・泊まり・明けなどの勤務カテゴリを組み合わせて、登録しやすくするための設定です。CSVのカテゴリをもとに勤務名候補を表示します。

泊まりと明けの組み合わせ

泊まり勤務ごとに、いっしょに登録する明け勤務を決めます。例：B2 → X2。明け勤務候補が複数ある場合は、ここで組み合わせを保存してください。

自動追加とコピー

最初の組み合わせをもとに同じ番号の組み合わせを自動追加できます。また、他の勤務セットにも同じ組み合わせをコピーできます。

What is a duty set?

A duty set combines duty categories such as day, stay, and after duties to make registration easier. Candidate duty names are shown based on CSV categories.

Stay and after-duty pairings

Set which after duty should be registered together with each stay duty. Example: B2 → X2. If multiple after-duty candidates exist, save the correct pairing here.

Auto-add and copy

You can auto-add pairings with the same numbering based on the first pair, and copy the same pairings to other duty sets.

意図しない明け勤務が選ばれる場合や、「明け勤務が複数あります」と表示される場合は、勤務セット編集で「泊まりと明けの組み合わせ」を設定してください。
If an unexpected after duty is selected or the app says multiple after duties exist, configure “Stay and after-duty pairings” in Duty Set Edit.

Siri / ショートカットで登録

Registering with Siri / Shortcuts

使える呼びかけ

  1. 「出場アラームで日勤登録」
  2. 「出場アラームで泊まり登録」
  3. 画面の案内に従って、勤務区分や勤務名を選択します。
  4. 選択後にアラームが登録されます。

音声認識が不安な場合

C3などの短い勤務名は誤認識されることがあります。Siriでは候補リストからタップして選ぶ方が確実です。候補は広めに表示されますが、登録時にカテゴリとの整合性を確認します。

Example phrases

  1. “Register day duty in CrewAlarm”
  2. “Register stay duty in CrewAlarm”
  3. Follow the prompts and select the duty type and duty name.
  4. Alarms are registered after selection.

If speech recognition is unreliable

Short duty names such as C3 may be misrecognized. Selecting from the Siri candidate list is more reliable. Candidates may be shown broadly, but registration is validated against the selected categories.

Using Apple Watch

勤務登録

Apple Watchの出場アラームから「勤務登録」を開き、日勤または泊まりを選びます。iPhone側で読み込んだCSVと勤務セットを使って登録します。

泊まり登録

保存済み勤務セットを選び、泊まり勤務名を選択します。明け勤務は勤務セット編集の組み合わせを優先して自動で選ばれます。

全削除

Apple Watchから登録済みアラームを全削除できます。削除前には確認画面が表示されます。

Duty registration

Open “Duty Registration” in the Apple Watch app, then choose a day duty or stay duty. Registration uses the CSV and duty sets loaded on iPhone.

Stay duty registration

Select a saved duty set and choose a stay duty name. The after duty is automatically selected using saved pairings in Duty Set Edit.

Delete all

You can delete all registered alarms from Apple Watch. A confirmation screen appears before deletion.

Apple Watchで勤務登録を使うには、先にiPhone側でCSV読み込みと勤務セット編集を済ませてください。勤務セットを変更した場合は、Watchアプリを開き直すと最新データを取得します。
To use duty registration on Apple Watch, first import the CSV and configure duty sets on iPhone. If you edit duty sets, reopen the Watch app to fetch the latest data.

事前通知

10

Pre-alert notifications

アラーム時刻のさらに前に通知

事前通知は、実際に鳴るアラーム時刻のさらに○分前に通知する機能です。起床・出場・確認通知ごとにオン／オフと通知タイミングを設定できます。

例：
基準時刻：07:30
出場アラーム：5分前 → 07:25に鳴る
事前通知：10分前 → 07:15に通知

通知文の編集

起床・出場の事前通知文は設定画面で編集できます。以下の文字を入れると、通知時に自動で置き換わります。

{title}      アラーム名
{notifyTime} アラーム時刻
{baseTime}   基準時刻
{minutes}    事前通知の分数

Notify before the alarm time

A pre-alert notification appears a configured number of minutes before the actual alarm time. You can configure it separately for wake-up, report, and check notifications.

Example:
Base time: 07:30
Report alarm: 5 minutes before → rings at 07:25
Pre-alert: 10 minutes before → notifies at 07:15

Editing notification text

You can customize the pre-alert message for wake-up and report alarms. The following placeholders are automatically replaced when the notification is shown.

{title}      Alarm title
{notifyTime} Alarm time
{baseTime}   Base time
{minutes}    Pre-alert minutes

Check notification settings

アラーム確認通知をAlarmKitのアラームとして登録します。停止後は次アラーム進行の対象になります。
通知のみ確認通知をアラームとして鳴らさず、iPhoneやApple Watchへの通知でお知らせします。通知時刻を過ぎた項目は完了済みとして扱われます。
使用しない確認通知のアラームも通知も登録しません。
AlarmRegisters check notifications as AlarmKit alarms. After stopping, they are included in next-alarm progression.
Notification onlyDoes not ring as an alarm. Instead, it sends a notification to iPhone or Apple Watch and is treated as completed after its notification time passes.
OffNo alarm or notification is registered for check notification times.

Dynamic Island / Live Activity

Dynamic Island / Live Activity

Live Activityとは

ロック画面やDynamic Islandに「次のアラーム」を表示する補助機能です。

Apple Watchにも表示

対応している環境では、Apple WatchにもLive Activityや次アラーム情報が表示されます。

表示が消えた時

長時間の表示、低電力状態、集中モード、iOSの判断などにより、表示が消えたり更新されないことがあります。

What is Live Activity?

Live Activity is a supplemental display that shows the next alarm on the Lock Screen or Dynamic Island.

Also shown on Apple Watch

In supported environments, Live Activity or next alarm information may also appear on Apple Watch.

If the display disappears

Live Activity may disappear or stop updating due to long display time, Low Power Mode, Focus mode, or iOS behavior.

FAQ

CSVを読み込めません。

ヘッダー名が指定フォーマットと一致しているか確認してください。Excelの場合は「CSV UTF-8」で保存すると改善することがあります。

NumbersやExcelのファイルをそのまま読み込めますか？

Numbers形式やExcel形式のままではなく、CSV形式に書き出してから読み込んでください。

Siriで勤務名がうまく認識されません。

C3などの短い勤務名は誤認識される場合があります。Siri画面に表示される候補リストからタップして選ぶ方法がおすすめです。

泊まり勤務で意図しない明け勤務が選ばれます。

勤務セット編集で「泊まりと明けの組み合わせ」を設定してください。例：B2 → X2 のように保存すると、その組み合わせが優先されます。

Apple Watchで勤務登録できません。

iPhone側でCSV読み込みと勤務セット編集を済ませ、アラームや通知の許可確認を完了してください。Watchアプリを開き直すと最新データを取得します。

ウィジェットの残り時間が少し遅れて見えることがあります。

iOSの仕様により、ウィジェットは常にリアルタイム更新されるわけではありません。必要に応じてアプリ本体の登録済みアラーム一覧も確認してください。

Dynamic IslandやLive Activityが消えました。

iOSの仕様により表示されなくなる場合があります。設定からLive Activityをオフにして、もう一度オンにすると復活する場合があります。

The CSV cannot be imported.

Check that the header names match the required format. If you use Excel, saving as CSV UTF-8 may help.

Can I import Numbers or Excel files directly?

Please export the spreadsheet as a CSV file first. Numbers and Excel files cannot be imported directly.

Siri does not recognize my duty name well.

Short duty names such as C3 may be misrecognized. Selecting from the candidate list shown by Siri is recommended.

An unexpected after duty is selected for a stay duty.

Configure “Stay and after-duty pairings” in Duty Set Edit. For example, saving B2 → X2 makes that pairing take priority.

I cannot register duties from Apple Watch.

On iPhone, import the CSV, configure duty sets, and complete alarm or notification permission prompts. Reopen the Watch app to fetch the latest data.

The widget countdown seems delayed.

Due to iOS widget behavior, widgets may not update in real time. Please also check the registered alarm list in the app when needed.

Dynamic Island or Live Activity disappeared.

This can happen due to iOS behavior. Turning Live Activity off and on again in Settings may restore the display.
