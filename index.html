What is CrewAlarm?

CSVから一括作成

勤務表CSVを読み込むだけで、その勤務に必要なアラーム候補を自動で作成します。

泊まり＋明けに対応

日勤だけでなく、泊まり勤務と明け勤務の組み合わせにも対応します。

端末内で処理

CSVデータやアラーム情報は端末内で処理されます。ログインや外部サーバー通信はありません。

Create alarms from CSV

Import a duty roster CSV file, and the app automatically prepares the alarm candidates needed for that duty.

Supports stay and after-duty patterns

The app supports day duties as well as stay-and-after-duty combinations.

Processed on your device

CSV data and alarm information are processed on your device. No login or external server communication is required.

Initial setup

まずはこの順番で進めてください

  1. アプリを起動し、通知やLive Activityの許可を確認します。
  2. NumbersまたはExcelでCSVファイルを作ります。
  3. CSVファイルをiPhoneの「ファイル」アプリに保存します。
  4. アプリの「CSVを読み込む」から勤務表CSVを選択します。
  5. 勤務セットと仕業を選び、「この勤務で全アラーム登録」をタップします。

許可について

アラーム、事前通知、Live Activity表示のために、iOSの許可画面が表示される場合があります。表示されたら許可してください。

通知AlarmKitLive Activity

Follow these steps first

  1. Open the app and allow notifications or Live Activities if prompted.
  2. Create a CSV file using Numbers or Excel.
  3. Save the CSV file to the Files app on iPhone.
  4. Select your duty roster CSV from “Import CSV”.
  5. Select the duty set and duty code, then tap “Register all alarms for this duty”.

Permissions

iOS may ask for permission to use alarms, pre-alert notifications, and Live Activity displays. Please allow them when prompted.

How to prepare a CSV file

必要な列名

CSVには、以下の列名を含めてください。複数の出場時刻は、1つのセルの中でカンマ区切りにします。英語の列名にも対応しています。

勤務名,カテゴリ,基準アラーム時刻（カンマ区切り）,基準起床時間,確認通知の時間
A1,平日日勤,"07:11,10:23,13:28",06:40,07:38
B1,平日泊まり,"16:54,19:34,22:45",15:30,
C1,平日明け,"07:13,10:18",06:40,07:37
勤務名カテゴリ基準アラーム時刻
カンマ区切り		基準起床時間確認通知の時間
A1平日日勤07:11,10:23,13:2806:4007:38
B1平日泊まり16:54,19:34,22:4515:30
C1平日明け07:13,10:1806:4007:37

NumbersやExcelでは、この表のように1行目へ列名を入れ、2行目以降に勤務データを入力します。

Required column names

The CSV file must include the following columns. If there are multiple report times, put them in one cell separated by commas. English column names are also supported.

Duty Name,Category,Base Alarm Times,Wake-up Time,Check Notification Time
A1,Weekday Day,"07:11,10:23,13:28",06:40,07:38
B1,Weekday Stay,"16:54,19:34,22:45",15:30,
C1,Weekday After,"07:13,10:18",06:40,07:37
Duty NameCategoryBase Alarm Times
comma-separated		Wake-up TimeCheck Notification Time
A1Weekday Day07:11,10:23,13:2806:4007:38
B1Weekday Stay16:54,19:34,22:4515:30
C1Weekday After07:13,10:1806:4007:37

In Numbers or Excel, put the column names in the first row and enter duty data from the second row onward.

時刻は「07:30」のように24時間表記で入力してください。CSVを読み込めない場合は、列名が一致しているか、複数時刻がカンマ区切りになっているかを確認してください。
Enter times in 24-hour format, such as “07:30”. If the CSV cannot be imported, check that the column names match and that multiple times are comma-separated.

NumbersでCSVを作る方法

5

Creating a CSV file with Numbers

MacのNumbersで作る場合

  1. Numbersを開き、新規書類を作成します。
  2. 1行目に「勤務名」「カテゴリ」「基準アラーム時刻（カンマ区切り）」「基準起床時間」「確認通知の時間」を入力します。
  3. 2行目以降に勤務データを入力します。
  4. 複数の出場時刻は、同じセルの中に「07:11,10:23,13:28」のように入力します。
  5. メニューの「ファイル」→「書き出す」→「CSV」を選びます。
  6. 文字コードを選べる場合は「Unicode（UTF-8）」を選び、保存します。

iPhone / iPadのNumbersで作る場合

  1. Numbersアプリで表を作成します。
  2. Mac版と同じ列名を1行目に入力します。
  3. 右上の「…」または共有ボタンをタップします。
  4. 「書き出し」または「送信」から「CSV」を選びます。
  5. 保存先に「ファイルに保存」を選びます。
  6. 「このiPhone内」または「iCloud Drive」に保存します。

Using Numbers on Mac

  1. Open Numbers and create a new spreadsheet.
  2. Enter “Duty Name”, “Category”, “Base Alarm Times”, “Wake-up Time”, and “Check Notification Time” in the first row.
  3. Enter duty data from the second row onward.
  4. For multiple report times, enter them in the same cell, such as “07:11,10:23,13:28”.
  5. Choose File → Export To → CSV.
  6. If available, choose Unicode (UTF-8), then save the file.

Using Numbers on iPhone / iPad

  1. Create a spreadsheet in the Numbers app.
  2. Enter the same column names in the first row.
  3. Tap the “…” button or share button.
  4. Choose Export or Send, then select CSV.
  5. Choose “Save to Files”.
  6. Save it to “On My iPhone” or “iCloud Drive”.
Numbersで作る場合、表の中にタイトル行や説明文を追加せず、1行目からCSV用の列名を入れると読み込みが安定します。
When using Numbers, avoid adding extra title rows or notes above the table. Put the CSV column names directly in the first row for stable import.

ExcelでCSVを作る方法

6

Creating a CSV file with Excel

Mac / WindowsのExcelで作る場合

  1. Excelを開き、新しいブックを作成します。
  2. 1行目に必要な列名を入力します。
  3. 2行目以降に勤務データを入力します。
  4. 時刻は「07:30」のように24時間表記で入力します。
  5. 「ファイル」→「名前を付けて保存」を選びます。
  6. ファイル形式で「CSV UTF-8（コンマ区切り）」を選んで保存します。

Excelで気をつけること

Excelは時刻を自動変換することがあります。表示が「7:30」になっても読み込める場合がありますが、うまくいかない時はセルの表示形式を「文字列」にしてから入力してください。

おすすめの入力例
07:30
16:54
23:10
00:25
CSV UTF-8コンマ区切り24時間表記

Using Excel on Mac / Windows

  1. Open Excel and create a new workbook.
  2. Enter the required column names in the first row.
  3. Enter duty data from the second row onward.
  4. Use 24-hour time format, such as “07:30”.
  5. Choose File → Save As.
  6. Select “CSV UTF-8 (Comma delimited)” and save the file.

Important Excel notes

Excel may automatically convert time values. If import does not work as expected, set the cells to Text format before entering times.

Recommended examples
07:30
16:54
23:10
00:25
CSV UTF-8Comma delimited24-hour format
「CSV」とだけ表示される保存形式には、文字化けしやすいものがあります。選べる場合は「CSV UTF-8」をおすすめします。
Some CSV formats may cause garbled Japanese text. If available, “CSV UTF-8” is recommended.

CSVをiPhoneに保存して読み込む方法

7

Saving the CSV file to iPhone and importing it

方法1：iCloud Driveを使う

  1. MacやWindowsでCSVを作成します。
  2. iCloud DriveにCSVファイルを保存します。
  3. iPhoneの「ファイル」アプリを開きます。
  4. iCloud Drive内にCSVがあることを確認します。
  5. 出場アラームで「CSVを読み込む」をタップし、そのCSVを選びます。

方法2：AirDropを使う

  1. MacでCSVファイルを右クリックします。
  2. 「共有」→「AirDrop」を選びます。
  3. 自分のiPhoneを選びます。
  4. iPhone側で受け取り、「ファイル」アプリに保存します。
  5. 出場アラームから保存したCSVを選びます。

方法3：メールやLINEから保存

  1. CSVファイルをメールやLINEでiPhoneに送ります。
  2. 添付ファイルを開きます。
  3. 共有ボタンをタップします。
  4. 「ファイルに保存」を選びます。
  5. 保存後、出場アラームからCSVを読み込みます。

Method 1: Use iCloud Drive

  1. Create the CSV file on Mac or Windows.
  2. Save the CSV file to iCloud Drive.
  3. Open the Files app on iPhone.
  4. Confirm that the CSV file is visible in iCloud Drive.
  5. In CrewAlarm, tap “Import CSV” and select the file.

Method 2: Use AirDrop

  1. Right-click the CSV file on Mac.
  2. Choose Share → AirDrop.
  3. Select your iPhone.
  4. On iPhone, accept the file and save it to the Files app.
  5. Select the saved CSV file from CrewAlarm.

Method 3: Save from email or messaging apps

  1. Send the CSV file to your iPhone by email or messaging app.
  2. Open the attached file.
  3. Tap the share button.
  4. Choose “Save to Files”.
  5. Import the saved CSV from CrewAlarm.
保存場所は「このiPhone内」でも「iCloud Drive」でも大丈夫です。迷った場合は、あとで見つけやすいように「iCloud Drive」内に「出場アラーム」などのフォルダを作って保存するのがおすすめです。
You can save the file either “On My iPhone” or in “iCloud Drive”. If unsure, create a folder such as “CrewAlarm” in iCloud Drive so the file is easy to find later.

アラームを登録する

8

Registering alarms

登録手順

  1. 勤務セットを選択します。
  2. 泊まり＋明けの場合は、泊まり仕業と明け仕業を選択します。
  3. 「この勤務で全アラーム登録」をタップします。
  4. ホームの次アラームカード、または登録済みアラーム一覧で内容を確認します。

基準時刻とアラーム時刻

基準時刻は勤務表上の元時刻です。アラーム時刻は、設定した「○分前」を引いた実際に鳴る時刻です。

例：
基準時刻 07:30
出場アラーム 5分前
実際に鳴る時刻 07:25

Steps

  1. Select a duty set.
  2. For stay-and-after duties, select both the stay duty and after duty.
  3. Tap “Register all alarms for this duty”.
  4. Check the Next Alarm card or the registered alarm list.

Base time and alarm time

The base time is the original time from the duty roster. The alarm time is the actual time after subtracting the configured offset.

Example:
Base time 07:30
Report alarm 5 minutes before
Actual alarm time 07:25
9

事前通知

9

Pre-alert notifications

アラーム時刻のさらに前に通知

事前通知は、実際に鳴るアラーム時刻のさらに○分前に通知する機能です。起床・出場・確認通知ごとにオン／オフと通知タイミングを設定できます。

例：
基準時刻：07:30
出場アラーム：5分前 → 07:25に鳴る
事前通知：10分前 → 07:15に通知

通知文の編集

起床・出場の事前通知文は設定画面で編集できます。以下の文字を入れると、通知時に自動で置き換わります。

{title}      アラーム名
{notifyTime} アラーム時刻
{baseTime}   基準時刻
{minutes}    事前通知の分数

Notify before the alarm time

A pre-alert notification appears a configured number of minutes before the actual alarm time. You can configure it separately for wake-up, report, and check notifications.

Example:
Base time: 07:30
Report alarm: 5 minutes before → rings at 07:25
Pre-alert: 10 minutes before → notifies at 07:15

Editing notification text

You can customize the pre-alert message for wake-up and report alarms. The following placeholders are automatically replaced when the notification is shown.

{title}      Alarm title
{notifyTime} Alarm time
{baseTime}   Base time
{minutes}    Pre-alert minutes

Check notification settings

通知のみ確認通知をアラームとして鳴らさず、iPhoneやApple Watchへの通知でお知らせします。確認通知一覧で確認できます。
使用しない確認通知のアラームも通知も登録しません。
AlarmRegisters check notifications as AlarmKit alarms. After stopping, they are included in next-alarm progression.
Notification onlyDoes not ring as an alarm. Instead, it sends a notification to iPhone or Apple Watch and can be checked in the check notification list.

Dynamic Island / Live Activity / Apple Watch

11

Dynamic Island / Live Activity / Apple Watch

Live Activityとは

ロック画面やDynamic Islandに「次のアラーム」を表示する補助機能です。アプリを開かなくても、次に鳴る予定のアラームを確認しやすくなります。

Apple Watchにも表示

対応している環境では、Apple WatchにもLive Activityや次アラーム情報が表示されます。手元で次の予定を確認したい時に便利です。

表示が消えた時

長時間の表示、低電力状態、集中モード、iOSの判断などにより、表示が消えたり更新されないことがあります。設定からLive Activityを一度オフにして、もう一度オンにすると復活する場合があります。

What is Live Activity?

Live Activity is a supplemental display that shows the next alarm on the Lock Screen or Dynamic Island, making it easier to check without opening the app.

Also shown on Apple Watch

In supported environments, Live Activity or next alarm information may also appear on Apple Watch, making it easier to check upcoming alarms from your wrist.

If the display disappears

Live Activity may disappear or stop updating due to long display time, Low Power Mode, Focus mode, or iOS behavior. Turning Live Activity off and on again in Settings may restore the display.

Live ActivityやDynamic Islandは補助表示です。オンにしていると、端末の状態によってはバッテリー消費が少し早くなる場合があります。大切なのは、Live Activityの表示ではなく、登録済みアラームと通知が正しく登録されていることです。
Live Activity and Dynamic Island are supplemental displays. Keeping them enabled may slightly increase battery usage depending on device conditions. The most important thing is that alarms and notifications are correctly registered, regardless of the Live Activity display state.

小さい画面のiPhone向け表示

Display on smaller iPhones

小さい画面のiPhoneでは、勤務選択時にスクロール操作とホイールピッカー操作が重なりやすい場合があります。そのため、該当端末ではメニュー方式を標準表示にし、設定画面からホイールピッカー表示に切り替えられるようにしています。

On smaller iPhones, scrolling and wheel picker gestures can overlap during duty selection. For those devices, the app uses menu-style selection by default, and you can switch back to wheel pickers from Settings.

FAQ

CSVを読み込めません。

ヘッダー名が指定フォーマットと一致しているか確認してください。特に「基準アラーム時刻（カンマ区切り）」や「確認通知の時間」の表記に注意してください。Excelの場合は「CSV UTF-8」で保存すると改善することがあります。

NumbersやExcelのファイルをそのまま読み込めますか？

Numbers形式やExcel形式のままではなく、CSV形式に書き出してから読み込んでください。

CSVはどこに保存すればいいですか？

iPhoneの「ファイル」アプリで見える場所に保存してください。「このiPhone内」または「iCloud Drive」がおすすめです。

確認通知をアラームではなく通知だけにできますか？

できます。設定画面の「確認通知」で「通知のみ」を選ぶと、iPhoneやApple Watchに通知だけ届きます。

確認通知カードが出ません。

設定画面で確認通知が「通知のみ」になっているか確認してください。「アラーム」や「使用しない」の場合、確認通知カードは表示されません。

Dynamic IslandやLive Activityが消えました。

iOSの仕様により表示されなくなる場合があります。設定からLive Activityをオフにして、もう一度オンにすると復活する場合があります。

バッテリー消費が気になります。

Live Activityをオンにしていると、通常より少しバッテリー消費が早くなる場合があります。不要な時は設定からオフにしてください。

通知が来ません。

iPhoneの設定アプリで通知許可がオンになっているか確認してください。また、アプリ内の事前通知設定がオンになっているか確認してください。

The CSV cannot be imported.

Check that the header names match the required format. Pay special attention to the base alarm times column and check notification time column. If you use Excel, saving as CSV UTF-8 may help.

Can I import Numbers or Excel files directly?

Please export the spreadsheet as a CSV file first. Numbers and Excel files cannot be imported directly.

Where should I save the CSV file?

Save it somewhere visible in the Files app, such as “On My iPhone” or “iCloud Drive”.

Can check notifications be notifications only?

Yes. In Settings, choose “Notification only” for check notifications. They will be delivered as notifications to iPhone or Apple Watch.

The check notification card is not shown.

Make sure the check notification mode is set to “Notification only” in Settings. If it is set to “Alarm” or “Off”, the check notification card is not shown.

Dynamic Island or Live Activity disappeared.

This can happen due to iOS behavior. Turning Live Activity off and on again in Settings may restore the display.

I am concerned about battery usage.

Keeping Live Activity enabled may slightly increase battery usage. Turn it off in Settings when you do not need it.

I do not receive notifications.

Check that notification permission is enabled in the iPhone Settings app, and confirm that pre-alert notifications are enabled inside CrewAlarm.
